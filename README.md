# Verse Preflight

> **This is an unofficial Star Citizen fan project, not affiliated with the Cloud Imperium group of companies. All content in this project not authored by its developers or users is property of their respective owners.**
> Official site: [robertsspaceindustries.com](https://robertsspaceindustries.com)

**Patch day? Run Preflight.** A free, open-source tool for Star Citizen players that gets your
game ready after every patch:

- **Folder links:** keep your control mappings, custom characters and screenshots in a folder
  you choose (for example a cloud-synced folder shared between PCs). Patches can't wipe them,
  and your existing files are never overwritten: conflicting copies are backed up instead.
  Every link can be undone.
- **Cache cleaner:** clears the shader cache and other leftovers the game rebuilds, with a
  checkbox and an explanation for each item.
- **StarStrings (optional):** installs or updates MrKraken's community
  [StarStrings](https://github.com/MrKraken/StarStrings) pack, checking that it matches your
  game build first. Your other `user.cfg` settings are kept.
- **Character viewer (experimental):** a rotatable 3D view of your saved custom characters
  (face shape, skin, eyes, hair and beard), rebuilt on your PC from your own game install.

Verse Preflight never modifies the game's executables or `Data.p4k` (the character viewer only
reads it), never interacts with the running game, and collects no data.

## Download

Verse Preflight runs on Windows 10 (version 2004) or later and needs Star Citizen installed.

- **GitHub:** [Releases](https://github.com/dougbillings/VersePreFlight/releases/latest)
  - **VersePreflight-win-Setup.exe** installs for your Windows user (no admin needed) and updates itself.
  - **VersePreflight-win-Portable.zip** runs from any folder, for example one synced between PCs.
- **Microsoft Store:** coming soon. Microsoft signs and updates the Store version.

The GitHub downloads are code-signed using free code signing provided by
[SignPath.io](https://about.signpath.io), with a certificate by [SignPath Foundation](https://signpath.org).
See the [code signing policy](#code-signing-policy). Releases made before signing was set up are unsigned.

## Building

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download).

```sh
dotnet test
dotnet run --project src/VersePreflight.App
```

The app icon is generated from code: `dotnet run tools/IconGen/IconGen.cs`
(add `-- --preview preview.png` to see the small sizes enlarged).

### Releases

Releases are built by GitHub Actions when a version tag is pushed (`git tag v0.1.0 && git push origin v0.1.0`).
Tags with a suffix such as `v0.2.0-beta.1` become pre-releases. Each release has:

- **Setup.exe**: per-user install (no admin) with Start menu and desktop shortcuts and automatic updates.
- **Portable.zip**: unzip anywhere; settings are kept next to the app, one file per PC.

Packaging uses [Velopack](https://velopack.io). To build a release locally:

```sh
dotnet publish src/VersePreflight.App -p:PublishProfile=win-x64 -p:Version=0.1.0 -o publish
dotnet tool restore
dotnet vpk pack -u VersePreflight -v 0.1.0 -p publish -e VersePreflight.exe -i src/VersePreflight.App/Assets/app.ico
```

The same workflow also builds the **Microsoft Store package** (`.msix`) and keeps it as a workflow artifact
for upload in Partner Center; the Store signs it and delivers updates. To build it locally (Windows):

```sh
pwsh tools/Msix/build-msix.ps1 -Version 0.1.0
```

The Store version is updated by the Store, so it never runs the GitHub update check. Its manifest and
logos are in `packaging/msix` (the logos are generated by IconGen).

The app checks this repository's GitHub Releases for new versions at startup (it can be turned off in
Settings). No other network requests are made, apart from StarStrings downloads when enabled.
See the [privacy policy](PRIVACY.md).

## Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by
[SignPath Foundation](https://signpath.org).

- **Committers and reviewers:** [dougbillings](https://github.com/dougbillings)
- **Approvers:** [dougbillings](https://github.com/dougbillings)

Only files built from this repository's source by its GitHub Actions release workflow are signed:
the app (`VersePreflight.exe`) and the installer (`VersePreflight-win-Setup.exe`). Every signing
request is approved by hand. Velopack's own `Update.exe`, an upstream MIT-licensed component, is
included unsigned. Releases made before the SignPath Foundation approval are unsigned. The Microsoft
Store version is signed by Microsoft.

**Privacy:** Verse Preflight collects no data and sends no information about the user or their PC
to any networked system. Its only connections are ordinary downloads from GitHub: the check for new versions (on by default, shown on
the first-run screen and can be turned off in Settings; the Microsoft Store version never does it)
and StarStrings downloads when the user turns that option on. See the [privacy policy](PRIVACY.md).
