## Store listing → Description

```text
Requires Star Citizen, installed separately on this PC. Verse Preflight is an unofficial Star Citizen fan project, not affiliated with the Cloud Imperium group of companies.

Patch day? Run Preflight. Verse Preflight gets your game ready after every patch, in one click.

FOLDER LINKS
Keep your control mappings, custom characters and screenshots in a folder you choose, for example a cloud-synced folder shared between your desktop and a handheld gaming PC. Patches can't wipe them, and your existing files are never overwritten: if the game has a different copy, it's backed up instead. Every link can be undone.

CACHE CLEANER
Clear the shader cache and other leftovers the game rebuilds after a patch. Each item has a checkbox and a plain explanation, so you decide what goes.

STARSTRINGS (OPTIONAL)
Install and update StarStrings, the community-made string pack by MrKraken, downloaded directly from the author's own releases. Verse Preflight checks that it matches your game build and asks first if it doesn't. Your other user.cfg settings are kept.

CHARACTER VIEWER (EXPERIMENTAL)
See your saved custom characters in 3D: face shape, skin, eyes, hair and beard, rebuilt on your PC from your own game install.

SAFE BY DESIGN
• Never modifies the game's executables or Data.p4k, and never interacts with the running game.
• Won't change anything while the game or its launcher is running.
• No account, no ads and no data collection.
• Free and open source under the MIT License.

Star Citizen®, Squadron 42®, Roberts Space Industries® and Cloud Imperium® are registered trademarks of Cloud Imperium Rights LLC.
```

## Submission options → Restricted capabilities (runFullTrust justification)

```text
Verse Preflight is a desktop (Win32) app packaged as MSIX. It needs runFullTrust to do its job in the user's Star Citizen installation, which is outside the package: it creates directory junctions there so the user's control mappings, characters and screenshots live in a folder they choose; deletes cache folders the user selects; writes an optional localization file; and reads the game's own data files to show the user's saved characters. It installs no drivers or services and changes no Windows settings. It is free and open source (MIT License).
```

## Submission options → Notes for certification

```text
Verse Preflight is a free, open-source companion utility for the PC game Star Citizen (an unofficial fan project, not affiliated with the game's publisher). There is no account, login or in-app purchase. Its main features need a Star Citizen install, which testers are unlikely to have, so here is how to test it without the game:

1. Create these empty folders: C:\SCTest\StarCitizen\LIVE\user\client\0
2. Start Verse Preflight. On the first-time setup screen, set GAME FOLDER to C:\SCTest\StarCitizen (the hint below it changes to "Found: LIVE"), keep the suggested LINK FOLDER, tick "I understand this is an unofficial, fan-made tool." and press SAVE.
3. Press LINK FOLDERS. The LIVE card shows Screenshots, Control mappings and Custom characters as LINKED. The three folders inside C:\SCTest\StarCitizen\LIVE are now directory junctions into Documents\VersePreflight.
4. Press UNDO LINKS and confirm with UNDO LINKS. The junctions are replaced by normal folders again.
5. CLEAN CACHE lists only caches that exist, so it is empty without the game. That is expected.
6. The CHARACTERS tab shows "No custom characters found..." or a message that no game install with game data was found. That is expected: it renders the user's own saved characters from their own game files.
7. STARSTRINGS is off by default (Settings). When enabled, it downloads a community translation file from its author's GitHub releases into the game folder.

The app makes no network requests of its own unless StarStrings is enabled; the Store version has no self-updater. Buttons such as FEEDBACK > OPEN ON GITHUB and ABOUT > SOURCE CODE only open a web page in the user's browser. Privacy policy: https://github.com/dougbillings/VersePreFlight/blob/main/PRIVACY.md
```
