# Privacy Policy

**Effective date:** October 14, 2026

Verse Preflight is a free, open-source tool for Star Citizen players. It is an unofficial fan
project, not affiliated with the Cloud Imperium group of companies.

**In short:** Verse Preflight does not collect, store or send any personal information. It has no
accounts, no telemetry, no analytics and no ads. The developers receive nothing from the app.

## What stays on your PC

Verse Preflight works with files on your own computer. All of the following stays on your PC (or,
for the portable version, in the folder you put the app in):

- **Settings:** your game folder, your link folder and which features are turned on.
- **Log:** a record of what the app did, including folder paths on your PC.
- **Caches:** head and hair data the Characters tab reads from your own game install, kept so the
  next start is faster.
- **Backups:** the previous copy of the StarStrings `global.ini` file, and any game files that
  differed from your copies when folders were linked.

The app reads your game install and your saved characters only to show them to you. It never sends
them anywhere.

## When the app connects to the internet

Verse Preflight only connects to GitHub, and only for these reasons:

- **Update check (versions downloaded from GitHub only).** At startup the app asks this project's
  GitHub Releases page whether a newer version exists. You can turn this off in Settings. The
  Microsoft Store version never does this; the Store handles its updates.
- **StarStrings (optional, off by default).** If you turn StarStrings on, the app downloads
  MrKraken's StarStrings files from that project's GitHub releases.

These are ordinary download requests. Like any website, GitHub receives your IP address and the
app's name and version. No personal information, game data or files from your PC are sent.
See the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Feedback and bug reports

The FEEDBACK button never sends anything by itself. It either copies your report to the clipboard
or opens a pre-filled GitHub issue page in your browser, where you can read and edit everything
before deciding whether to submit it. If you include diagnostics, your Windows user name and PC
name are replaced with placeholders first. Anything you submit on GitHub is public and covered by
GitHub's privacy statement.

## Microsoft Store

If you install Verse Preflight from the Microsoft Store, Microsoft handles the download, install
and updates under the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).
Verse Preflight does not receive any information about you from the Store.

## Children

Verse Preflight does not collect personal information from anyone, including children.
